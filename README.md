# 观己 (GuanJi) · 奇门命盘分析与老师预约 Web App

> 「看见自己的模式，找到值得深入了解的方向。」  
> 手机优先（Mobile-First 390px 适配）高品质中文命盘认知镜像与个人咨询预约应用。

---

## 一、项目设计理念与调性

本项目摒弃传统算命网站充斥的玄虚符号、恐吓式断言、大面积金色渐变与紫色科技感。整体视觉与体验对标**现代高品质个人咨询应用**：
- **安静有温度**：暖白底色（`#FAF9F5`）、深墨绿主色（`#183226`）、香槟金点缀（`#C3A675`）与深灰正文（`#232825`）。
- **尊重用户主体性**：命理解读定位于传统文化认知透镜，旨在帮助用户反思内在矛盾与行为习惯，不提供宿命论断言、绝不伪造准确率或虚假好评。
- **真正交付免费价值**：免费报告提供完整的心智张力剖析、因果复盘、反思提问与可执行的 48 小时微行动，不以“付费看后半段”逼迫用户。
- **老师的角色**：结合咨询者的真实生活经历进一步追问与探讨，协助厘清模式背景与行动方向。

## 二、页面与流程架构

```
/ (首页)
  ├── 核心主标题与三大价值支柱
  ├── /report/sample (基准示例报告入口)
  └── /assessment (分步资料输入)
        ├── 步骤一：称呼、公历日期、24H时间、国家城市、时区推荐、未知时间处理
        ├── 步骤二：切入主题（自我/事业/关系/困惑）、具体补充问题（≤300字）
        ├── 步骤三：资料总览核对（防AM/PM混淆）、出生隐私说明与主动授权
        └── /assessment/analyzing (真实三阶段处理状态)
              └── /report/[id] (完整深度报告展示)
                    ├── A. 个人资料与排盘摘要（四柱、流派、真太阳时调整说明）
                    ├── B. 一句话内在矛盾概括
                    ├── C. 三个核心倾向（标题、解释、生活投射、命盘依据展开、反思提问）
                    ├── D. 容易重复的行为模式（清晰因果分析）
                    ├── E. 当前值得厘清的问题（2-3个深挖提问）
                    ├── F. 一条可以尝试的小行动（48小时微实验）
                    ├── G. 互动奇门命盘（九宫格展开、点击单元格查阅客观词典）
                    ├── H. 用户真实反馈（贴近度评价与经历补充，拒绝虚假百分比）
                    └── I. 深入解读老师入口 & 手机底部常驻吸顶按钮
                          └── /teachers (老师列表，RM 定价，服务方式)
                                └── /teachers/[id] (老师详情、解读方法、流程、准备、WhatsApp)
                                      └── /booking/[teacherId] (预约申请流程，主动报告授权，待确认状态说明)

/my-reports (当前设备已存报告，本地隐私存储、安全分享、一键删除)
/teacher (老师演示后台沙箱，预约管理、授权报告查看、严格隔离的私人笔记 vs 客户摘要)
```

## 三、快速开始

### 1. 环境要求
- Node.js >= 18.17.0 (推荐 Node 20+)
- npm >= 9.0.0

### 2. 安装与运行
```bash
# 进入项目目录
cd "Ai奇门遁甲"

# 安装依赖（若尚未安装）
npm install

# 启动本地开发服务
npm run dev

# 浏览器访问
http://localhost:3000
```

### 3. 生产打包与验证
```bash
# 执行类型检查与生产环境静态/动态编译
npm run build

# 启动生产服务
npm run start
```

## 五、正式上线前待确认与接入清单

### 1. 奇门排盘流派与算法规范（核心算法层）
- [ ] **排盘法确认**：确定采用「拆补法」、「置闰法」或「茅山派」统一算法。
- [ ] **子时换日规范**：早子时（00:00-01:00）与夜子时（23:00-24:00）的干支归属标准。
- [ ] **真太阳时与节气数据**：接入国家授时中心/天文历法数据库，精确到分秒的经纬度真太阳时校准。
- [ ] **中五宫寄宫规则**：明确天禽星与死门落中五宫时寄坤二宫或艮八宫规则。
- 替换路径：实现 `src/services/chart/chart-engine.interface.ts` 中的 `IChartEngine` 即可无缝替换当前 `sample-chart-engine.ts`。

### 2. AI 智能解读服务（AI Provider 层）
- [ ] **服务端密钥管理**：配置 `OPENAI_API_KEY`、`GEMINI_API_KEY` 或 `ANTHROPIC_API_KEY` 于服务端环境变量（如 `.env.local`），严禁暴露于前端或客户端打包文件。
- [ ] **结构化校验**：AI 仅接收排盘引擎输出的确定性九宫 JSON，不允许 AI 自行推算天干八门；使用 JSON Schema 强校验输出。
- 替换路径：实现 `src/services/analysis/analysis-provider.interface.ts` 中的 `IAnalysisProvider` 接口。

### 3. 数据持久化与用户认证（Auth & Database）
- [ ] 接入正式数据库（如 PostgreSQL / Supabase）。
- [ ] 建立用户系统（NextAuth / Supabase Auth），开放跨设备同步并支持 GDPR / 个人信息保护法（PIPL）的随时注销与数据清除。
- [ ] 老师后台接入 RBAC 权限守卫，仅允许认证老师调阅受客户明确授权的预约与报告。

### 4. 商业化与通讯渠道（Payment & Notification）
- [ ] **WhatsApp 号码配置**：在 `src/config/brand.ts` 中填入客服/咨询老师真实 WhatsApp 号码（例如 `+60123456789`）。
- [ ] **支付网关接入**：接入马来西亚本地网关（如 Stripe、Billplz、ToyyibPay 或 FPX）处理 RM 咨询费用。
- [ ] **自动化通知**：配置 Resend / SendGrid 或 WhatsApp Business API，在预约状态变更时自动向用户与老师发送提醒。
